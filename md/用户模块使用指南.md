# 用户模块使用指南

## 📋 概述

用户模块提供了完整的用户管理功能，包括用户信息查询、用户列表分页查询、用户创建、用户更新、用户删除以及更改密码等功能。

## 🚀 快速开始

### 1. 获取当前用户信息

**接口：** `GET /api/user/info`

**功能：** 获取当前登录用户的详细信息，包含角色和按钮权限

**请求示例：**

```bash
curl -X GET "http://localhost:3000/api/user/info" \
  -H "Authorization: Bearer <token>"
```

**响应示例：**

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "userId": 1,
    "userName": "admin",
    "nickName": "管理员",
    "email": "admin@example.com",
    "avatar": "https://example.com/avatar.jpg",
    "roles": ["admin"],
    "buttons": ["user:add", "user:edit", "user:delete"]
  }
}
```

### 2. 分页查询用户列表

**接口：** `GET /api/user/list`

**功能：** 分页获取用户列表，支持按用户名、昵称、邮箱、手机号、状态筛选

**请求参数：**

| 参数      | 类型   | 必填 | 说明                            |
| --------- | ------ | ---- | ------------------------------- |
| current   | number | 否   | 当前页码，从 1 开始，默认 1     |
| size      | number | 否   | 每页数量，默认 10，最大 100     |
| userName  | string | 否   | 用户名（模糊查询）              |
| nickName  | string | 否   | 昵称（模糊查询）                |
| email     | string | 否   | 邮箱（模糊查询）                |
| userPhone | string | 否   | 手机号（模糊查询）              |
| status    | string | 否   | 状态：'1'（启用）或 '2'（禁用） |

**请求示例：**

```bash
curl -X GET "http://localhost:3000/api/user/list?current=1&size=10&userName=admin" \
  -H "Authorization: Bearer <token>"
```

**响应示例：**

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "records": [
      {
        "id": 1,
        "userName": "admin",
        "nickName": "管理员",
        "email": "admin@example.com",
        "userPhone": "13800138000",
        "userGender": "male",
        "status": "1",
        "avatar": "https://example.com/avatar.jpg",
        "createBy": 1,
        "createTime": "2025-01-01T00:00:00.000Z",
        "updateBy": 1,
        "updateTime": "2025-01-01T00:00:00.000Z"
      }
    ],
    "current": 1,
    "size": 10,
    "total": 100
  }
}
```

### 3. 创建用户

**接口：** `POST /api/user`

**功能：** 创建一个新的用户

**请求体：**

```json
{
  "userName": "newuser",
  "password": "password123",
  "nickName": "新用户",
  "email": "newuser@example.com",
  "userPhone": "13800138001",
  "userGender": "male",
  "status": "1",
  "avatar": "https://example.com/avatar.jpg",
  "remark": "备注信息"
}
```

**响应示例：**

```json
{
  "code": 201,
  "message": "success",
  "data": {
    "id": 2,
    "userName": "newuser",
    "nickName": "新用户",
    "email": "newuser@example.com",
    "userPhone": "13800138001",
    "userGender": "male",
    "status": "1",
    "avatar": "https://example.com/avatar.jpg",
    "createBy": 1,
    "createTime": "2025-01-01T00:00:00.000Z"
  }
}
```

### 4. 更新用户

**接口：** `PUT /api/user/:id`

**功能：** 根据 ID 更新用户信息

**请求体：**

```json
{
  "nickName": "更新后的昵称",
  "email": "updated@example.com",
  "userPhone": "13800138002",
  "userGender": "female",
  "status": "1",
  "avatar": "https://example.com/new-avatar.jpg",
  "remark": "更新后的备注"
}
```

**注意：** 如果提供了 `password` 字段，密码会被加密并更新。但建议使用专门的更改密码接口。

### 5. 删除用户

**接口：** `DELETE /api/user/:id`

**功能：** 根据 ID 删除用户（硬删除）

**请求示例：**

```bash
curl -X DELETE "http://localhost:3000/api/user/2" \
  -H "Authorization: Bearer <token>"
```

**响应示例：**

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "id": 2,
    "userName": "newuser",
    "nickName": "新用户",
    "email": "newuser@example.com"
  }
}
```

### 6. 更改密码

**接口：** `POST /api/user/change-password`

**功能：** 更改当前登录用户的密码

**请求体：**

```json
{
  "oldPassword": "oldPassword123",
  "newPassword": "newPassword123",
  "confirmPassword": "newPassword123"
}
```

**密码要求：**

- 新密码长度至少 8 位
- 新密码必须包含字母和数字
- 新密码不能与当前密码相同
- 新密码和确认密码必须一致

**响应示例：**

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "message": "密码修改成功"
  }
}
```

**安全特性：**

- 验证旧密码是否正确
- 密码加密存储（使用 bcrypt）
- 密码修改后更新密码版本号，使旧 Token 失效
- 用户需要重新登录

**错误响应：**

```json
{
  "code": 401,
  "message": "当前密码不正确"
}
```

```json
{
  "code": 400,
  "message": "新密码和确认密码不一致"
}
```

```json
{
  "code": 400,
  "message": "新密码不能与当前密码相同"
}
```

## 📝 核心组件

### 1. UserController

**文件位置：** `src/modules/user/user.controller.ts`

**功能：**

- 定义用户相关的 API 端点
- 处理 HTTP 请求和响应
- 使用 JWT 认证保护所有接口

**关键装饰器：**

- `@UseGuards(JwtAuthGuard)` - 所有接口都需要 JWT 认证
- `@ApiBearerAuth()` - Swagger 文档中的 Bearer Token 认证
- `@CurrentUser('userId')` - 获取当前登录用户 ID

### 2. UserService

**文件位置：** `src/modules/user/user.service.ts`

**功能：**

- 实现用户相关的业务逻辑
- 数据库操作（使用 Prisma）
- 密码加密和验证（使用 bcrypt）
- 密码版本号管理（使用 Redis）

**关键方法：**

- `getUserInfo(userId)` - 获取用户信息（包含角色和权限）
- `findPaginated(query)` - 分页查询用户列表
- `create(createUserDto, currentUserId)` - 创建用户
- `update(id, updateUserDto, currentUserId)` - 更新用户
- `remove(id)` - 删除用户
- `changePassword(userId, changePasswordDto)` - 更改密码

### 3. DTOs

**文件位置：** `src/modules/user/dto/`

**DTO 列表：**

- `CreateUserDto` - 创建用户请求参数
- `UpdateUserDto` - 更新用户请求参数
- `QueryUserDto` - 查询用户列表请求参数（继承 `PaginationDto`）
- `ChangePasswordDto` - 更改密码请求参数
- `UserResponseDto` - 用户响应数据
- `UserInfoResponseDto` - 用户信息响应数据

### 4. ChangePasswordDto

**文件位置：** `src/modules/user/dto/change-password.dto.ts`

**字段说明：**

```typescript
{
  oldPassword: string; // 当前密码
  newPassword: string; // 新密码（至少8位，包含字母和数字）
  confirmPassword: string; // 确认新密码
}
```

**验证规则：**

- `oldPassword` - 必填，不能为空
- `newPassword` - 必填，至少 8 位，必须包含字母和数字
- `confirmPassword` - 必填，至少 8 位，必须与新密码一致

## 🔒 安全特性

### 1. 密码加密

所有密码都使用 bcrypt 加密存储：

```typescript
const hashedPassword = await bcrypt.hash(password, 10);
```

### 2. 密码版本号

当用户更改密码时，系统会：

1. 更新数据库中的密码
2. 更新 Redis 中的密码版本号（递增）
3. 使所有旧的 Token 失效（通过 JWT Strategy 验证密码版本号）

**实现原理：**

```typescript
// 获取当前密码版本号
const currentVersion = await this.cacheManager.get<string>(
  getRedisKey(USER_VERSION_KEY, userId),
);
const newVersion = currentVersion ? parseInt(currentVersion, 10) + 1 : 1;

// 更新密码版本号
await this.cacheManager.set(
  getRedisKey(USER_VERSION_KEY, userId),
  newVersion.toString(),
  7 * 24 * 60 * 60 * 1000, // 7天过期时间
);
```

### 3. Token 失效机制

JWT Token 中包含密码版本号（`pv`），每次验证 Token 时：

1. 从 Token 中提取密码版本号
2. 从 Redis 中获取当前密码版本号
3. 比较两个版本号，如果不一致，Token 失效

**相关代码：**

- `src/modules/auth/strategies/jwt.strategy.ts` - JWT Strategy 验证密码版本号
- `src/modules/auth/auth.service.ts` - `validateToken` 方法验证密码版本号

## 💻 使用示例

### 前端调用示例

```typescript
import { fetchChangePassword } from '@/api/user';

// 更改密码
const handleChangePassword = async () => {
  try {
    await fetchChangePassword({
      oldPassword: 'oldPassword123',
      newPassword: 'newPassword123',
      confirmPassword: 'newPassword123',
    });

    // 密码修改成功，自动登出
    ElMessage.success('密码修改成功，请重新登录');
    setTimeout(() => {
      userStore.logOut();
    }, 1500);
  } catch (error) {
    // 错误已在拦截器中处理
    console.error('密码修改失败:', error);
  }
};
```

## 🎯 关键要点

### 1. 所有接口都需要认证

用户模块的所有接口都使用 `@UseGuards(JwtAuthGuard)` 保护，需要提供有效的 JWT Token。

### 2. 密码修改后需要重新登录

密码修改成功后，系统会更新密码版本号，使所有旧的 Token 失效。用户需要重新登录获取新的 Token。

### 3. 密码验证

更改密码时会验证：

- 旧密码是否正确
- 新密码是否符合要求（至少 8 位，包含字母和数字）
- 新密码是否与旧密码相同
- 新密码和确认密码是否一致

### 4. 创建人和更新人

创建和更新用户时，系统会自动记录 `createBy` 和 `updateBy` 字段（从 `@CurrentUser` 装饰器获取）。

### 5. 密码字段不返回

所有用户响应数据中都不包含 `password` 字段，确保密码不会泄露。
