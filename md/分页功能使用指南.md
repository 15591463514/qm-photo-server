# 分页功能使用指南

## 📋 概述

项目集成了统一的分页功能，包括分页请求参数、分页管道、分页响应等完整的分页解决方案。

## 🚀 快速开始

### 1. 基本使用

在 Controller 中使用分页功能：

```typescript
import { Controller, Get, Query } from '@nestjs/common';
import {
  ApiTags,
  ApiOperation,
  ApiQuery,
  ApiExtraModels,
} from '@nestjs/swagger';
import { PaginationPipe } from '@/common/pipes/pagination.pipe';
import { PaginationParams } from '@/common/dto/pagination.dto';
import { QueryTestDto } from './dto/query-test.dto';
import { PaginationDto } from '@/common/dto/pagination.dto';
import { ApiResult } from '@/common/decorators/api-result.decorator';
import { TestResponseDto } from './dto/test-response.dto';

@ApiTags('test')
@Controller('test')
export class TestController {
  @Get()
  @ApiOperation({
    summary: '分页查询测试数据',
    description: '分页获取未删除的测试数据列表，支持按名称和状态筛选',
  })
  @ApiExtraModels(QueryTestDto, PaginationDto) // 注册模型，确保 Swagger 能识别查询参数
  @ApiQuery({ type: QueryTestDto }) // 指定查询参数类型
  @ApiResult({
    status: 200,
    description: '查询成功',
    type: [TestResponseDto],
    isPage: true, // 标记为分页响应
  })
  findPaginated(
    @Query(PaginationPipe)
    query: QueryTestDto,
  ) {
    return this.testService.findPaginated(query);
  }
}
```

### 2. Service 实现

```typescript
import { Injectable } from '@nestjs/common';
import { QueryTestDto } from './dto/query-test.dto';
import { PaginatedDto } from '@/common/dto/paginated.dto';
import { createPaginatedResponse } from '@/common/helpers/pagination.helper';

@Injectable()
export class TestService {
  async findPaginated(
    query: QueryTestDto,
  ): Promise<PaginatedDto<TestResponseDto>> {
    const { skip, take, page, pageSize, name, status } = query;

    // 构建查询条件
    const where: any = {
      deletedAt: null,
    };

    if (name) {
      where.name = { contains: name };
    }
    if (status !== undefined) {
      where.status = status;
    }

    // 并行查询数据和总数
    const [results, totalItems] = await Promise.all([
      this.prisma.test.findMany({
        where,
        orderBy: { createdAt: 'desc' },
        skip,
        take,
      }),
      this.prisma.test.count({ where }),
    ]);

    // 转换数据
    const items = results.map((result) =>
      plainToInstance(TestResponseDto, result, {
        excludeExtraneousValues: false,
      }),
    );

    // 创建分页响应
    return createPaginatedResponse(
      items,
      { skip, take, page, pageSize },
      totalItems,
    );
  }
}
```

## 📝 核心组件

### 1. PaginationDto（请求参数 DTO）

**文件位置：** `src/common/dto/pagination.dto.ts`

用于定义分页请求参数：

```typescript
export class PaginationDto {
  @ApiPropertyOptional({
    description: '页码，从 1 开始',
    example: 1,
    default: 1,
  })
  @Type(() => Number)
  @IsInt()
  @Min(1)
  @IsOptional()
  page?: number = 1;

  @ApiPropertyOptional({
    description: '每页数量',
    example: 10,
    default: 10,
    maximum: 100,
  })
  @Type(() => Number)
  @IsInt()
  @Min(1)
  @Max(100)
  @IsOptional()
  pageSize?: number = 10;

  /* mysql忽略条数 */
  public skip: number;

  /* mysql返回条数 */
  public take: number;
}
```

**参数说明：**

- `page` - 页码，从 1 开始，默认值为 1
- `pageSize` - 每页数量，默认值为 10，最大值为 100
- `skip` - 数据库查询的跳过数量（由 `PaginationPipe` 自动计算，`skip = (page - 1) * pageSize`）
- `take` - 数据库查询的返回数量（由 `PaginationPipe` 自动设置，`take = pageSize`）

### 2. PaginationPipe（分页管道）

**文件位置：** `src/common/pipes/pagination.pipe.ts`

自动将 `page` 和 `pageSize` 转换为数据库查询需要的 `skip` 和 `take`：

```typescript
@Injectable()
export class PaginationPipe implements PipeTransform {
  transform(value: any, metadata: ArgumentMetadata) {
    // 验证并转换分页参数
    // 返回包含 skip, take, page, pageSize 的对象
  }
}
```

**功能：**

- 验证分页参数（页码必须 >= 1，每页数量必须在 1-100 之间）
- 将 `page` 和 `pageSize` 转换为数据库查询需要的 `skip` 和 `take`
- 返回包含 `skip`、`take`、`page`、`pageSize` 的分页参数对象
- 使用常量统一管理默认值和最大值

**注意：** `PaginationPipe` 返回的是分页参数对象，NestJS 会自动将其合并到查询 DTO 中。由于 `QueryTestDto` 继承了 `PaginationDto`，而 `PaginationDto` 包含 `skip` 和 `take` 属性，所以这些属性会被正确设置。

### 3. PaginatedDto（响应 DTO）

**文件位置：** `src/common/dto/paginated.dto.ts`

定义分页响应结构：

```typescript
export class PaginatedDto<T> {
  items: T[]; // 数据列表
  meta: PaginationMetaDto; // 分页元数据
}

export class PaginationMetaDto {
  currentPage: number; // 当前页码
  itemsPerPage: number; // 每页数量
  totalItems: number; // 总记录数
  totalPages: number; // 总页数
  itemCount: number; // 当前页记录数
}
```

### 4. 分页辅助函数

**文件位置：** `src/common/helpers/pagination.helper.ts`

提供创建分页响应的辅助函数：

```typescript
export function createPaginatedResponse<T>(
  items: T[],
  paginationParams: PaginationParams,
  totalItems: number,
): PaginatedDto<T>;
```

## 💻 使用示例

### 创建查询 DTO（继承 PaginationDto）

```typescript
import { ApiPropertyOptional } from '@nestjs/swagger';
import { IsString, IsOptional, IsBoolean } from 'class-validator';
import { PaginationDto } from '@/common/dto/pagination.dto';

export class QueryTestDto extends PaginationDto {
  @ApiPropertyOptional({
    description: '测试名称（模糊查询）',
    example: '测试',
  })
  @IsString()
  @IsOptional()
  name?: string;

  @ApiPropertyOptional({
    description: '状态',
    example: true,
  })
  @IsBoolean()
  @IsOptional()
  status?: boolean;
}
```

### Controller 中使用

```typescript
import {
  ApiTags,
  ApiOperation,
  ApiQuery,
  ApiExtraModels,
} from '@nestjs/swagger';
import { QueryTestDto } from './dto/query-test.dto';
import { PaginationDto } from '@/common/dto/pagination.dto';

@Get()
@ApiOperation({ summary: '分页查询测试数据' })
@ApiExtraModels(QueryTestDto, PaginationDto) // 注册模型，确保 Swagger 能识别查询参数
@ApiQuery({ type: QueryTestDto }) // 指定查询参数类型
@ApiResult({
  status: 200,
  description: '查询成功',
  type: [TestResponseDto],
  isPage: true, // 重要：标记为分页响应
})
findPaginated(
  @Query(PaginationPipe)
  query: QueryTestDto,
) {
  return this.testService.findPaginated(query);
}
```

**关键点：**

- `@ApiExtraModels()` - 注册 DTO 模型，确保 Swagger 能识别查询参数
- `@ApiQuery({ type: QueryTestDto })` - 指定查询参数类型，Swagger 会自动展开 DTO 中的属性
- `@Query(PaginationPipe)` - 使用分页管道自动处理分页参数

### Service 中使用

```typescript
import { Injectable } from '@nestjs/common';
import { plainToInstance } from 'class-transformer';
import { QueryTestDto } from './dto/query-test.dto';
import { PaginatedDto } from '@/common/dto/paginated.dto';
import { createPaginatedResponse } from '@/common/helpers/pagination.helper';

@Injectable()
export class TestService {
  async findPaginated(
    query: QueryTestDto,
  ): Promise<PaginatedDto<TestResponseDto>> {
    // 直接解构查询对象，包含分页参数和过滤条件
    const { skip, take, page, pageSize, name, status } = query;

    // 构建查询条件
    const where: any = { deletedAt: null };
    if (name) where.name = { contains: name };
    if (status !== undefined) where.status = status;

    // 并行查询数据和总数，提高性能
    const [results, totalItems] = await Promise.all([
      this.prisma.test.findMany({
        where,
        orderBy: { createdAt: 'desc' },
        skip,
        take,
      }),
      this.prisma.test.count({ where }),
    ]);

    // 转换数据
    const items = results.map((result) =>
      plainToInstance(TestResponseDto, result, {
        excludeExtraneousValues: false,
      }),
    );

    // 创建分页响应
    return createPaginatedResponse(
      items,
      { skip, take, page, pageSize },
      totalItems,
    );
  }
}
```

**关键点：**

- **直接接收完整查询对象**：Service 接收 `QueryTestDto`，由于 `QueryTestDto` 继承了 `PaginationDto`，所以包含所有分页参数（`page`、`pageSize`、`skip`、`take`）和业务查询条件（`name`、`status`）
- **直接解构使用**：可以直接解构 `skip`、`take`、`page`、`pageSize` 等字段，这些字段由 `PaginationPipe` 自动设置
- **并行查询**：使用 `Promise.all` 同时查询数据和总数，提高性能

## 🎯 关键要点

### 1. 使用 PaginationPipe

在 Controller 中使用 `@Query(PaginationPipe)` 装饰器，管道会自动：

- 验证分页参数
- 转换为 `skip` 和 `take`
- 将分页参数（`skip`、`take`、`page`、`pageSize`）设置到查询对象中

**注意：** 由于 `QueryTestDto` 继承了 `PaginationDto`，而 `PaginationDto` 包含 `skip` 和 `take` 属性，`PaginationPipe` 返回的分页参数会被正确合并到查询对象中。

### 2. 配置查询参数 Swagger 文档

在 Controller 中使用 `@ApiExtraModels()` 和 `@ApiQuery()` 装饰器，确保 Swagger 能正确显示查询参数：

```typescript
@ApiExtraModels(QueryTestDto, PaginationDto) // 注册模型
@ApiQuery({ type: QueryTestDto }) // 指定查询参数类型
```

这样 Swagger 会自动展开 DTO 中的所有属性（包括继承的 `PaginationDto` 属性），显示完整的查询参数文档。

### 3. 标记分页响应

在 `@ApiResult` 装饰器中设置 `isPage: true`，Swagger 会自动生成正确的分页响应结构。

### 4. 并行查询

在 Service 中使用 `Promise.all` 并行查询数据和总数，提高性能。

### 5. 使用辅助函数

使用 `createPaginatedResponse` 函数创建分页响应，确保格式统一。
