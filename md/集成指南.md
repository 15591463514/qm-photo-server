# NestJS项目初期必备库和工具集成指南

## 前言

最近在搭建一个家庭监控应用的后端，技术栈选择了NestJS。踩了不少坑之后，总结了一套比较实用的库集成方案。

如果你也在用NestJS开发项目，不知道该先装哪些库，或者想避免一些常见的坑，这篇文章应该对你有帮助 🚀

## 按优先级的集成方案

### 第一优先级：项目基础设施

#### 1. 配置管理

```bash
pnpm add @nestjs/config
```

支持多环境配置，全局可用。

#### 2. 数据库集成（Prisma）

```bash
pnpm add prisma @prisma/client
npx prisma init
```

#### 3. API文档（Swagger）

```bash
pnpm add @nestjs/swagger swagger-ui-express
pnpm add class-validator class-transformer
```

自动生成API文档，提升开发效率。

**已集成：** ✅ 项目已集成 Swagger，访问 `http://localhost:3000/api` 查看文档。

**详细说明：** 查看 [Swagger使用指南](./Swagger使用指南.md)

#### 4. 分页功能

统一的分页功能，包括分页请求参数、分页管道、分页响应等完整解决方案。

**已集成：** ✅ 项目已集成分页功能，支持统一的分页查询。

**详细说明：** 查看 [分页功能使用指南](./分页功能使用指南.md)

#### 4. 身份认证

```bash
pnpm add @nestjs/jwt @nestjs/passport passport passport-jwt bcryptjs
```

### 第二优先级：开发体验与安全

#### 5. 日志管理

```bash
pnpm add winston nest-winston
```

结构化日志记录，便于问题排查。

#### 6. 安全防护

```bash
pnpm add helmet @nestjs/throttler
```

基础安全防护和API限流。

### 第三优先级：业务功能支撑

#### 8. 实时通信

```bash
pnpm add @nestjs/websockets @nestjs/platform-socket.io socket.io
```

#### 8. 文件上传

```bash
pnpm add multer @nestjs/platform-express
```

#### 9. 缓存系统

```bash
pnpm add @nestjs/cache-manager cache-manager cache-manager-redis-store redis
```

### 第四优先级：高级功能

#### 10. 任务调度

```bash
pnpm add @nestjs/schedule @nestjs/bull bull
```

#### 11. 健康检查

```bash
pnpm add @nestjs/terminus
```

## 推荐的项目结构

```md
src/
├── common/ # 通用模块
│ ├── decorators/ # 自定义装饰器
│ ├── filters/ # 异常过滤器
│ ├── guards/ # 权限守卫
│ └── interceptors/ # 拦截器
├── config/ # 配置文件
├── modules/ # 业务模块
│ ├── auth/ # 认证模块
│ ├── user/ # 用户管理
│ └── monitor/ # 监控功能
├── prisma/ # 数据库模式
├── utils/ # 工具函数
└── main.ts # 应用入口
```

## 5天集成时间规划

- **第1天**：配置管理 + Prisma + 基础CRUD
- **第2天**：Swagger + 异常处理
- **第3天**：JWT认证 + 权限控制
- **第4天**：日志 + CORS + API限流
- **第5天**：文件上传 + 静态资源服务

## 总结

按照这个顺序集成，好处还是很明显的：

1. **降低开发风险** - 先把基础设施搭好，后面写业务逻辑就不慌了
2. **提高开发效率** - 该有的工具都有了，开发起来爽很多
3. **代码质量有保障** - 类型安全、参数验证这些都帮你兜底
4. **团队协作更顺畅** - API文档、代码规范统一，新人上手也快

总之一句话：别急着写业务，先把"地基"打牢，后面会省很多事儿 💪
