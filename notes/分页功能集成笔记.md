### 2. 创建分页请求 DTO

**文件位置：** `src/common/dto/pagination.dto.ts`

**功能：**

- 定义分页请求参数
- 包含 Swagger 装饰器和验证装饰器

**关键代码：**

```typescript
import { ApiPropertyOptional } from '@nestjs/swagger';
import { Type } from 'class-transformer';
import { IsInt, IsOptional, Min, Max } from 'class-validator';
import { PAGINATION_CONSTANTS } from '../constants/pagination.constants';

export class PaginationDto {
  @ApiPropertyOptional({
    description: '当前页码，从 1 开始',
    default: PAGINATION_CONSTANTS.DEFAULT_PAGE,
    minimum: 1,
  })
  @Type(() => Number)
  @IsInt({ message: '当前页码必须是整数' })
  @Min(1, { message: '当前页码必须大于 0' })
  @IsOptional()
  current?: number = PAGINATION_CONSTANTS.DEFAULT_PAGE;

  @ApiPropertyOptional({
    description: '每页数量',
    default: PAGINATION_CONSTANTS.DEFAULT_PAGE_SIZE,
    minimum: 1,
    maximum: PAGINATION_CONSTANTS.MAX_PAGE_SIZE,
  })
  @Type(() => Number)
  @IsInt({ message: '每页数量必须是整数' })
  @Min(1, { message: '每页数量必须大于 0' })
  @Max(PAGINATION_CONSTANTS.MAX_PAGE_SIZE, {
    message: `每页数量不能超过 ${PAGINATION_CONSTANTS.MAX_PAGE_SIZE}`,
  })
  @IsOptional()
  size?: number = PAGINATION_CONSTANTS.DEFAULT_PAGE_SIZE;

  /* mysql忽略条数 */
  public skip: number;

  /* mysql返回条数 */
  public take: number;
}

export type PaginationParams = Pick<
  PaginationDto,
  'current' | 'size' | 'skip' | 'take'
>;
```

**装饰器说明：**

- `@ApiPropertyOptional()` - Swagger 文档中的可选属性
- `@Type(() => Number)` - 类型转换，将字符串转换为数字
- `@IsInt()` - 验证必须是整数
- `@Min()` / `@Max()` - 数值范围验证
- `@IsOptional()` - 标记为可选

**⚠️ 重要变更：**

- 字段名从 `page` 改为 `current`（与前端保持一致）
- 字段名从 `pageSize` 改为 `size`（与前端保持一致）
- 管道支持向后兼容，同时接受 `page`/`pageSize` 和 `current`/`size`

### 3. 创建分页响应 DTO

**文件位置：** `src/common/dto/paginated.dto.ts`

**功能：**

- 定义分页响应结构

**关键代码：**

```typescript
import { ApiProperty } from '@nestjs/swagger';

/**
 * 分页响应 DTO
 * @description 用于返回分页数据，包含数据列表和分页信息
 */
export class PaginatedDto<T> {
  @ApiProperty({
    description: '数据列表',
    type: 'array',
  })
  records: T[];

  @ApiProperty({
    description: '当前页码',
    example: 1,
  })
  current: number;

  @ApiProperty({
    description: '每页数量',
    example: 10,
  })
  size: number;

  @ApiProperty({
    description: '总记录数',
    example: 100,
  })
  total: number;
}
```

**⚠️ 重要变更：**

- 结构从嵌套的 `{ items: [], meta: {} }` 改为扁平化的 `{ records: [], current, size, total }`
- 字段名从 `items` 改为 `records`（与前端保持一致）
- 移除了 `PaginationMetaDto` 类，分页信息直接包含在响应中
- 移除了 `totalPages` 和 `itemCount` 字段，前端可根据 `total` 和 `size` 计算

### 4. 创建分页管道

**文件位置：** `src/common/pipes/pagination.pipe.ts`

**功能：**

- 验证分页参数
- 将 `current` 和 `size` 转换为 `skip` 和 `take`
- 支持向后兼容（同时接受 `page`/`pageSize` 和 `current`/`size`）

**关键代码：**

```typescript
@Injectable()
export class PaginationPipe implements PipeTransform {
  transform(value: any) {
    const maxPageSize = PAGINATION_CONSTANTS.MAX_PAGE_SIZE;
    const defaultPageSize = PAGINATION_CONSTANTS.DEFAULT_PAGE_SIZE;

    // 支持 current 或 page（向后兼容）
    let current: number = PAGINATION_CONSTANTS.DEFAULT_PAGE;
    const currentVal = value.current ?? value.page;
    if (currentVal !== undefined && currentVal !== null && currentVal !== '') {
      const parsed = Number(currentVal);
      current =
        Number.isInteger(parsed) && parsed >= 1
          ? parsed
          : PAGINATION_CONSTANTS.DEFAULT_PAGE;
    }

    // 支持 size 或 pageSize（向后兼容）
    let size: number = defaultPageSize;
    const sizeVal = value.size ?? value.pageSize;
    if (sizeVal !== undefined && sizeVal !== null && sizeVal !== '') {
      const parsed = Number(sizeVal);
      size =
        Number.isInteger(parsed) && parsed >= 1 && parsed <= maxPageSize
          ? parsed
          : defaultPageSize;
    }

    // 验证参数范围
    if (current < 1) {
      throw new BadRequestException('当前页码必须大于 0');
    }
    if (size < 1 || size > maxPageSize) {
      throw new BadRequestException(`每页数量必须在 1-${maxPageSize} 之间`);
    }

    // 计算数据库查询参数
    const skip = (current - 1) * size;
    const take = size;

    // 创建分页参数对象
    const paginationParams: PaginationDto = {
      skip,
      take,
      current,
      size,
    };

    return paginationParams;
  }
}
```

**关键点：**

- **向后兼容**：同时支持 `page`/`pageSize` 和 `current`/`size` 参数
- **扁平化展开**：将 `skip`、`take`、`current`、`size` 直接添加到查询对象中，方便直接使用
- **参数验证**：确保页码和每页数量在有效范围内（页码 >= 1，每页数量在 1-100 之间）
- **自动转换**：将业务层的 `current` 和 `size` 转换为数据库层的 `skip` 和 `take`
- **使用常量**：从 `PAGINATION_CONSTANTS` 获取默认值和最大值，统一管理配置

### 5. 创建分页辅助函数

**文件位置：** `src/common/helpers/pagination.helper.ts`

**功能：**

- 创建分页响应（扁平化结构）

**关键代码：**

```typescript
import { PaginationParams } from '../dto/pagination.dto';
import { PaginatedDto } from '../dto/paginated.dto';

/**
 * 创建分页响应
 * @param records 数据列表
 * @param paginationParams 分页参数
 * @param total 总记录数
 * @returns 分页响应
 */
export function createPaginatedResponse<T>(
  records: T[],
  paginationParams: PaginationParams,
  total: number,
): PaginatedDto<T> {
  const { current, size } = paginationParams;

  return {
    records,
    current,
    size,
    total,
  };
}
```

**⚠️ 重要变更：**

- 移除了 `createPaginationMeta` 函数
- `createPaginatedResponse` 直接返回扁平化结构

### 6. 在 Controller 中使用

**文件位置：** `src/modules/user/user.controller.ts`

**关键代码：**

```typescript
@Get('list')
@ApiOperation({
  summary: '获取用户列表（分页）',
  description: '分页获取用户列表，支持按用户名、昵称、邮箱、手机号、状态筛选',
})
@ApiExtraModels(QueryUserDto, PaginationDto)
@ApiQuery({ type: QueryUserDto })
@ApiResult({
  status: 200,
  description: '查询成功',
  type: [UserResponseDto],
  isPage: true,
})
@ApiResult({ status: 401, description: '未授权' })
findPaginated(@Query(PaginationPipe) query: QueryUserDto) {
  return this.userService.findPaginated(query);
}
```

**关键点：**

- `@ApiExtraModels(QueryUserDto, PaginationDto)` - 注册 DTO 模型，确保 Swagger 能识别查询参数
- `@ApiQuery({ type: QueryUserDto })` - 指定查询参数类型，Swagger 会自动展开 DTO 中的属性（包括继承的 `PaginationDto` 属性）
- 使用 `@Query(PaginationPipe)` 装饰器，自动处理分页参数
- `@ApiResult` 中设置 `isPage: true`，Swagger 会自动生成正确的分页响应结构

### 7. 在 Service 中使用

**文件位置：** `src/modules/user/user.service.ts`

**关键代码：**

```typescript
async findPaginated(
  query: QueryUserDto,
): Promise<PaginatedDto<UserResponseDto>> {
  const {
    skip,
    take,
    current,
    size,
    userName,
    nickName,
    email,
    userPhone,
    status,
  } = query;

  // 构建查询条件
  const where: Prisma.UserWhereInput = {};

  // 添加过滤条件
  if (userName) {
    where.userName = { contains: userName };
  }
  // ... 其他过滤条件

  // 并行查询数据和总数
  const [results, total] = await Promise.all([
    this.prisma.user.findMany({
      where,
      orderBy: { createTime: 'desc' },
      skip,
      take,
    }),
    this.prisma.user.count({ where }),
  ]);

  // 转换数据
  const records = results.map((result) => {
    const { password: _, ...userWithoutPassword } = result;
    return plainToInstance(UserResponseDto, {
      ...userWithoutPassword,
      id: userWithoutPassword.id,
    }, {
      excludeExtraneousValues: false,
    });
  });

  // 创建分页响应
  return createPaginatedResponse(
    records,
    { skip, take, current, size },
    total,
  );
}
```

**关键点：**

- 直接接收完整的查询对象，包含分页参数和过滤条件
- 使用 `Promise.all` 并行查询数据和总数，提高性能
- 使用 `createPaginatedResponse` 创建统一的分页响应格式
- 变量名从 `items` 改为 `records`，从 `totalItems` 改为 `total`

## 🔄 使用流程

### 1. 请求流程

3. Controller 接收处理后的查询对象

5. 响应转换拦截器包装为统一格式

## 💡 关键要点

### 1. 扁平化设计

分页参数扁平化展开到查询对象中，方便直接使用：

```typescript
// PaginationPipe 扁平化展开
return {
  skip,
  take,
  current,
  size,
};

// Service 中直接解构使用
const { skip, take, current, size, userName, status } = query;
```

**优势：**

- 代码更简洁，无需嵌套访问
- 使用更直观，可以直接访问 `skip`、`take`、`current`、`size` 等字段
- 避免命名冲突

### 2. 向后兼容

管道支持同时接受 `page`/`pageSize` 和 `current`/`size` 参数：

```typescript
// 支持两种方式
const currentVal = value.current ?? value.page;
const sizeVal = value.size ?? value.pageSize;
```

**优势：**

- 平滑迁移，旧代码可以继续工作
- 新代码使用新字段名，与前端保持一致

### 3. 类型安全

使用 TypeScript 类型系统确保类型安全：

```typescript
query: QueryUserDto; // 包含 current, size, skip, take 和业务查询条件
```

### 4. 并行查询

使用 `Promise.all` 并行查询数据和总数，提高性能：

```typescript
const [results, total] = await Promise.all([
  this.prisma.user.findMany({ where, skip, take }),

```

### 5. 统一响应格式

使用 `createPaginatedResponse` 创建统一的分页响应格式。

### 6. Swagger 集成
