### 2. 创建分页请求 DTO

**文件位置：** `src/common/dto/pagination.dto.ts`

**功能：**

- 定义分页请求参数
- 包含 Swagger 装饰器和验证装饰器

**关键代码：**

```typescript
import { ApiPropertyOptional } from '@nestjs/swagger';
import { Type } from 'class-transformer';
import { IsInt, IsOptional, Min, Max } from 'class-validator';
import { PAGINATION_CONSTANTS } from '../constants/pagination.constants';

export class PaginationDto {
  @ApiPropertyOptional({
    description: '页码，从 1 开始',
    example: 1,
    default: PAGINATION_CONSTANTS.DEFAULT_PAGE,
  })
  @Type(() => Number)
  @IsInt({ message: '页码必须是整数' })
  @Min(1, { message: '页码必须大于 0' })
  @IsOptional()
  page?: number = PAGINATION_CONSTANTS.DEFAULT_PAGE;

  @ApiPropertyOptional({
    description: '每页数量',
    example: PAGINATION_CONSTANTS.DEFAULT_PAGE_SIZE,
    default: PAGINATION_CONSTANTS.DEFAULT_PAGE_SIZE,
    maximum: PAGINATION_CONSTANTS.MAX_PAGE_SIZE,
  })
  @Type(() => Number)
  @IsInt({ message: '每页数量必须是整数' })
  @Min(1, { message: '每页数量必须大于 0' })
  @Max(PAGINATION_CONSTANTS.MAX_PAGE_SIZE, {
    message: `每页数量不能超过 ${PAGINATION_CONSTANTS.MAX_PAGE_SIZE}`,
  })
  @IsOptional()
  pageSize?: number = PAGINATION_CONSTANTS.DEFAULT_PAGE_SIZE;
}
```

**装饰器说明：**

- `@ApiPropertyOptional()` - Swagger 文档中的可选属性
- `@Type(() => Number)` - 类型转换，将字符串转换为数字
- `@IsInt()` - 验证必须是整数
- `@Min()` / `@Max()` - 数值范围验证
- `@IsOptional()` - 标记为可选

### 4. 创建分页管道

**文件位置：** `src/common/pipes/pagination.pipe.ts`

**功能：**

- 验证分页参数
- 将 `page` 和 `pageSize` 转换为 `skip` 和 `take`
- 扁平化展开分页参数到请求对象

**关键代码：**

```typescript
import {
  PipeTransform,
  Injectable,
  ArgumentMetadata,
  BadRequestException,
} from '@nestjs/common';
import { PaginationDto } from '../dto/pagination.dto';
import { PAGINATION_CONSTANTS } from '../constants/pagination.constants';

export interface PaginationParams {
  skip: number; // 跳过的记录数
  take: number; // 获取的记录数
  page: number; // 当前页码
  pageSize: number; // 每页数量
}

@Injectable()
export class PaginationPipe implements PipeTransform {
  transform(value: any, metadata: ArgumentMetadata) {
    // 如果不是分页 DTO，直接返回
    if (metadata.metatype !== PaginationDto) {
      return value;
    }

    // 获取最大每页数量和默认每页数量
    const maxPageSize = PAGINATION_CONSTANTS.MAX_PAGE_SIZE;
    const defaultPageSize = PAGINATION_CONSTANTS.DEFAULT_PAGE_SIZE;

    // 获取分页参数，设置默认值
    const page = value?.page || PAGINATION_CONSTANTS.DEFAULT_PAGE;
    const pageSize = value?.pageSize || defaultPageSize;

    // 验证参数
    if (page < 1) {
      throw new BadRequestException('页码必须大于 0');
    }
    if (pageSize < 1 || pageSize > maxPageSize) {
      throw new BadRequestException(`每页数量必须在 1-${maxPageSize} 之间`);
    }

    // 计算数据库查询参数
    const skip = (page - 1) * pageSize;
    const take = pageSize;

    // 创建分页参数对象
    const paginationParams: PaginationParams = {
      skip,
      take,
      page,
      pageSize,
    };

    // 扁平化展开分页参数
    return {
      ...value,
      ...paginationParams,
    };
  }
}
```

**关键点：**

- **扁平化展开**：将 `skip`、`take`、`page`、`pageSize` 直接添加到查询对象中，方便直接使用
- **参数验证**：确保页码和每页数量在有效范围内（页码 >= 1，每页数量在 1-100 之间）
- **自动转换**：将业务层的 `page` 和 `pageSize` 转换为数据库层的 `skip` 和 `take`
- **使用常量**：从 `PAGINATION_CONSTANTS` 获取默认值和最大值，统一管理配置

### 5. 创建分页辅助函数

**文件位置：** `src/common/helpers/pagination.helper.ts`

**功能：**

- 创建分页元数据
- 创建分页响应

**关键代码：**

```typescript
import { PaginationParams } from '../pipes/pagination.pipe';
import { PaginatedDto, PaginationMetaDto } from '../dto/paginated.dto';

export function createPaginationMeta(
  paginationParams: PaginationParams,
  totalItems: number,
): PaginationMetaDto {
  const { page, pageSize } = paginationParams;
  const totalPages = Math.ceil(totalItems / pageSize);
  const itemCount = Math.min(pageSize, totalItems - (page - 1) * pageSize);

  return {
    currentPage: page,
    itemsPerPage: pageSize,
    totalItems,
    totalPages,
    itemCount: itemCount > 0 ? itemCount : 0,
  };
}

export function createPaginatedResponse<T>(
  items: T[],
  paginationParams: PaginationParams,
  totalItems: number,
): PaginatedDto<T> {
  return {
    items,
    meta: createPaginationMeta(paginationParams, totalItems),
  };
}
```

### 6. 在 Controller 中使用

**文件位置：** `src/modules/test/test.controller.ts`

**关键代码：**

```typescript
import { Controller, Get, Query } from '@nestjs/common';
import {
  ApiTags,
  ApiOperation,
  ApiQuery,
  ApiExtraModels,
} from '@nestjs/swagger';
import {
  PaginationPipe,
  PaginationParams,
} from '@/common/pipes/pagination.pipe';
import { QueryTestDto } from './dto/query-test.dto';
import { PaginationDto } from '@/common/dto/pagination.dto';
import { ApiResult } from '@/common/decorators/api-result.decorator';
import { TestResponseDto } from './dto/test-response.dto';

@ApiTags('test')
@Controller('test')
export class TestController {
  @Get()
  @ApiOperation({
    summary: '分页查询测试数据',
    description: '分页获取未删除的测试数据列表，支持按名称和状态筛选',
  })
  @ApiExtraModels(QueryTestDto, PaginationDto) // 注册模型，确保 Swagger 能识别查询参数
  @ApiQuery({ type: QueryTestDto }) // 指定查询参数类型，Swagger 会自动展开 DTO 中的属性
  @ApiResult({
    status: 200,
    description: '查询成功',
    type: [TestResponseDto],
    isPage: true, // 重要：标记为分页响应
  })
  findPaginated(
    @Query(PaginationPipe)
    query: QueryTestDto & PaginationParams,
  ) {
    return this.testService.findPaginated(query);
  }
}
```

**关键点：**

- `@ApiExtraModels(QueryTestDto, PaginationDto)` - 注册 DTO 模型，确保 Swagger 能识别查询参数
- `@ApiQuery({ type: QueryTestDto })` - 指定查询参数类型，Swagger 会自动展开 DTO 中的属性（包括继承的 `PaginationDto` 属性）
- 使用 `@Query(PaginationPipe)` 装饰器，自动处理分页参数
- 类型定义：`QueryTestDto & PaginationParams`，包含查询条件和分页参数
- `@ApiResult` 中设置 `isPage: true`，Swagger 会自动生成正确的分页响应结构

### 7. 在 Service 中使用

**文件位置：** `src/modules/test/test.service.ts`

**关键代码：**

```typescript
import { Injectable } from '@nestjs/common';
import { plainToInstance } from 'class-transformer';
import { PaginationParams } from '@/common/pipes/pagination.pipe';
import { QueryTestDto } from './dto/query-test.dto';
import { PaginatedDto } from '@/common/dto/paginated.dto';
import { createPaginatedResponse } from '@/common/helpers/pagination.helper';

@Injectable()
export class TestService {
  async findPaginated(
    query: QueryTestDto & PaginationParams,
  ): Promise<PaginatedDto<TestResponseDto>> {
    const { skip, take, page, pageSize, name, status } = query;

    // 构建查询条件
    const where: any = {
      deletedAt: null,
    };

    if (name) {
      where.name = { contains: name };
    }
    if (status !== undefined) {
      where.status = status;
    }

    // 并行查询数据和总数
    const [results, totalItems] = await Promise.all([
      this.prisma.test.findMany({
        where,
        orderBy: { createdAt: 'desc' },
        skip,
        take,
      }),
      this.prisma.test.count({ where }),
    ]);

    // 转换数据
    const items = results.map((result) =>
      plainToInstance(TestResponseDto, result, {
        excludeExtraneousValues: false,
      }),
    );

    // 创建分页响应
    return createPaginatedResponse(
      items,
      { skip, take, page, pageSize },
      totalItems,
    );
  }
}
```

**关键点：**

- 直接接收完整的查询对象，包含分页参数和过滤条件
- 使用 `Promise.all` 并行查询数据和总数，提高性能
- 使用 `createPaginatedResponse` 创建统一的分页响应格式

## 🔄 使用流程

### 1. 请求流程

1. 客户端发送请求：`GET /test?page=1&pageSize=10&name=测试`
2. `PaginationPipe` 拦截请求，验证并转换参数
3. Controller 接收处理后的查询对象
4. Service 执行查询，返回分页响应
5. 响应转换拦截器包装为统一格式

## 💡 关键要点

### 1. 扁平化设计

分页参数扁平化展开到查询对象中，方便直接使用：

```typescript
// PaginationPipe 扁平化展开
return {
  ...value,
  ...paginationParams, // skip, take, page, pageSize 直接添加到查询对象
};

// Service 中直接解构使用
const { skip, take, page, pageSize, name, status } = query;
```

**优势：**

- 代码更简洁，无需嵌套访问 `_pagination`
- 使用更直观，可以直接访问 `skip`、`take` 等字段
- 避免命名冲突（`skip`、`take` 是数据库专用字段，业务 DTO 通常不会使用）

### 2. 直接传递完整查询对象

Controller 直接传递整个 `query` 对象到 Service，无需解构：

```typescript
// Controller - 直接传递
findPaginated(@Query(PaginationPipe) query: QueryTestDto & PaginationParams) {
  return this.testService.findPaginated(query);
}

// Service - 内部解构
async findPaginated(query: QueryTestDto & PaginationParams) {
  const { skip, take, page, pageSize, name, status } = query;
  // ...
}
```

**优势：**

- 代码更简洁，Controller 无需解构
- 职责更清晰，Service 自行处理查询参数
- 易于扩展，新增查询条件只需修改 Service

### 3. 类型安全

使用 TypeScript 类型系统确保类型安全：

```typescript
query: QueryTestDto & PaginationParams;
```

### 4. 并行查询

使用 `Promise.all` 并行查询数据和总数，提高性能：

```typescript
const [results, totalItems] = await Promise.all([
  this.prisma.test.findMany({ where, skip, take }),
  this.prisma.test.count({ where }),
]);
```

### 5. 统一响应格式

使用 `createPaginatedResponse` 创建统一的分页响应格式。

### 6. Swagger 集成

**查询参数文档配置：**

- 使用 `@ApiExtraModels(QueryTestDto, PaginationDto)` 注册模型，确保 Swagger 能识别查询参数
- 使用 `@ApiQuery({ type: QueryTestDto })` 指定查询参数类型，Swagger 会自动展开 DTO 中的所有属性（包括继承的 `PaginationDto` 属性）
- 每个查询参数都会在 Swagger 文档中显示，包括描述、示例值和验证规则

**响应文档配置：**

- 使用 `@ApiResult` 装饰器，设置 `isPage: true`，自动生成正确的分页响应结构
- Swagger 会自动识别 `{ items: [], meta: {} }` 的分页响应格式

### 7. 使用常量统一管理配置

所有分页相关的默认值和最大值都定义在常量文件中：

```typescript
export const PAGINATION_CONSTANTS = {
  DEFAULT_PAGE: 1,
  DEFAULT_PAGE_SIZE: 10,
  MAX_PAGE_SIZE: 100,
} as const;
```

**优势：**

- 统一管理，修改方便
- 类型安全，使用 `as const` 确保常量不可变
- 代码清晰，所有配置一目了然
