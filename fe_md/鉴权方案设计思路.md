## 需求分析

根据前端文档，系统需要实现以下功能：

### 1. 用户认证

- 用户登录（用户名+密码）
- JWT Token 认证（Access Token + Refresh Token）
- Token 刷新机制
- 用户登出

### 2. 权限控制

- **角色权限（RBAC）**：用户 → 角色 → 菜单
- **按钮权限**：角色 → 菜单 → 按钮（细粒度权限）
- 动态路由：根据用户角色返回可访问的菜单列表

### 3. 数据模型

- 用户表（users）
- 角色表（roles）
- 菜单表（menus）
- 菜单按钮表（menu_buttons）
- 用户角色关联表（user_roles）
- 角色菜单关联表（role_menus）
- 角色菜单按钮关联表（role_menu_buttons）

## 技术选型

### 1. Passport 认证框架

**使用：`@nestjs/passport` + `passport` + `passport-local`**

- `@nestjs/passport`：NestJS 官方 Passport 集成模块
- `passport`：Node.js 认证中间件，支持多种策略
- `passport-local`：本地策略（用户名+密码认证）

**安装：**

```bash
pnpm add @nestjs/passport passport passport-local
pnpm add -D @types/passport-local
```

### 2. JWT 认证

**使用：`@nestjs/jwt` + `passport-jwt`**

- `@nestjs/jwt`：NestJS 官方 JWT 模块，提供 JWT 服务
- `passport-jwt`：Passport 的 JWT 策略，用于验证 JWT Token

**安装：**

```bash
pnpm add @nestjs/jwt passport-jwt
pnpm add -D @types/passport-jwt
```

### 3. 密码加密

**推荐：`bcrypt`**

- 行业标准，安全性高
- 支持自动加盐
- 性能良好

**安装：**

```bash
pnpm add bcrypt
pnpm add -D @types/bcrypt
```

### 4. 权限装饰器

**自定义装饰器：**

- `@Public()` - 标记公开接口（无需认证）
- `@Roles(...roles)` - 标记需要特定角色
- `@Permissions(...permissions)` - 标记需要特定权限

### 5. 缓存（可选）

**使用 Redis 缓存用户权限信息**

- 减少数据库查询
- 提高性能
- 支持权限变更时清除缓存

### 2. 认证流程

#### 2.1 登录流程

```
客户端提交用户名和密码
    ↓
Local Auth Guard（使用 Local Strategy 验证）
    ↓
AuthService.validateUser()（验证用户名和密码，使用 Prisma 查询 User）
    ↓
验证成功，生成 JWT Token
    ↓
返回 Token 给前端
```

#### 2.2 请求认证流程

```
客户端请求（携带 Token）
    ↓
JWT Auth Guard（使用 JWT Strategy 验证 Token）
    ↓
从 Token 提取用户信息，查询用户角色（使用 Prisma）
    ↓
Roles Guard（验证角色，可选）
    ↓
Permissions Guard（验证权限，可选）
    ↓
Controller Handler
```

### 3. 权限验证流程

```
1. 从 Token 中提取用户信息（userId, roles）
   ↓
2. 查询用户角色（从数据库或缓存）
   ↓
3. 查询角色关联的菜单权限
   ↓
4. 查询角色关联的按钮权限
   ↓
5. 验证当前请求的菜单/按钮是否在权限列表中
```

## 核心流程

### 1. 登录流程

```
1. 用户提交用户名和密码
   ↓
2. Local Strategy 调用 AuthService.validateUser()
   ↓
3. AuthService 使用 Prisma 查询 User 表，验证密码（BCrypt）
   ↓
4. 验证成功，生成 Access Token 和 Refresh Token
   ↓
5. 返回 Token 给前端
   ↓
6. 前端存储 Token 到 localStorage
```

**代码示例：**

```typescript
// auth.service.ts
import { Injectable, UnauthorizedException } from '@nestjs/common';
import { JwtService } from '@nestjs/jwt';
import { PrismaService } from '@/shared/prisma.service';
import * as bcrypt from 'bcrypt';

@Injectable()
export class AuthService {
  constructor(
    private prisma: PrismaService,
    private jwtService: JwtService,
  ) {}

  // 验证用户（Local Strategy 调用）
  async validateUser(userName: string, password: string): Promise<any> {
    // 使用 Prisma 查询用户
    const user = await this.prisma.user.findUnique({
      where: { userName },
      include: {
        userRoles: {
          include: {
            role: true,
          },
        },
      },
    });

    if (!user) {
      throw new UnauthorizedException('用户名或密码错误');
    }

    // 验证用户状态
    if (user.status !== '1') {
      throw new UnauthorizedException('用户已被禁用');
    }

    // 验证密码（BCrypt）
    const isPasswordValid = await bcrypt.compare(password, user.password);
    if (!isPasswordValid) {
      throw new UnauthorizedException('用户名或密码错误');
    }

    // 返回用户信息（排除密码）
    const { password: _, ...result } = user;
    return result;
  }

  // 登录（生成 Token）
  async login(user: any) {
    // 提取角色编码
    const roles = user.userRoles?.map((ur: any) => ur.role.roleCode) || [];

    // 生成 Access Token
    const payload = {
      userId: user.id.toString(),
      userName: user.userName,
      roles,
    };
    const accessToken = this.jwtService.sign(payload, { expiresIn: '2h' });

    // 生成 Refresh Token
    const refreshToken = this.jwtService.sign(
      { ...payload, type: 'refresh' },
      { expiresIn: '7d' },
    );

    return {
      token: accessToken,
      refreshToken,
    };
  }
}
```

**Local Strategy 实现：**

```typescript
// strategies/local.strategy.ts
import { Strategy } from 'passport-local';
import { PassportStrategy } from '@nestjs/passport';
import { Injectable, UnauthorizedException } from '@nestjs/common';
import { AuthService } from '../auth.service';

@Injectable()
export class LocalStrategy extends PassportStrategy(Strategy) {
  constructor(private authService: AuthService) {
    super({
      usernameField: 'userName', // 指定用户名字段
      passwordField: 'password',
    });
  }

  async validate(userName: string, password: string): Promise<any> {
    const user = await this.authService.validateUser(userName, password);
    if (!user) {
      throw new UnauthorizedException();
    }
    return user;
  }
}
```

**Controller 实现：**

```typescript
// auth.controller.ts
import {
  Controller,
  Post,
  UseGuards,
  Request,
  HttpCode,
  HttpStatus,
} from '@nestjs/common';
import { AuthService } from './auth.service';
import { LocalAuthGuard } from './guards/local-auth.guard';

@Controller('auth')
export class AuthController {
  constructor(private authService: AuthService) {}

  @UseGuards(LocalAuthGuard) // 使用 Local Strategy
  @Post('login')
  @HttpCode(HttpStatus.OK)
  async login(@Request() req) {
    // req.user 由 Local Strategy 的 validate 方法返回
    return this.authService.login(req.user);
  }
}
```

### 2. Token 验证流程

```
1. 请求头中提取 Token（Authorization: Bearer {token}）
   ↓
2. JWT Strategy 验证 Token 有效性（使用 @nestjs/jwt）
   ↓
3. 从 Token 中提取用户信息（payload）
   ↓
4. 使用 Prisma 查询用户信息（验证用户状态）
   ↓
5. 将用户信息附加到 request.user
```

**代码示例：**

```typescript
// strategies/jwt.strategy.ts
import { Injectable, UnauthorizedException } from '@nestjs/common';
import { PassportStrategy } from '@nestjs/passport';
import { ExtractJwt, Strategy } from 'passport-jwt';
import { ConfigService } from '@nestjs/config';
import { PrismaService } from '@/shared/prisma.service';

export interface JwtPayload {
  userId: string;
  userName: string;
  roles: string[];
  iat?: number;
  exp?: number;
}

@Injectable()
export class JwtStrategy extends PassportStrategy(Strategy) {
  constructor(
    private configService: ConfigService,
    private prisma: PrismaService,
  ) {
    super({
      jwtFromRequest: ExtractJwt.fromAuthHeaderAsBearerToken(), // 从请求头提取 Token
      ignoreExpiration: false,
      secretOrKey: configService.get<string>('JWT_SECRET'),
    });
  }

  async validate(payload: JwtPayload) {
    // 使用 Prisma 查询用户
    const user = await this.prisma.user.findUnique({
      where: { id: BigInt(payload.userId) },
      include: {
        userRoles: {
          include: {
            role: true,
          },
        },
      },
    });

    // 验证用户存在且状态正常
    if (!user || user.status !== '1') {
      throw new UnauthorizedException('用户不存在或已被禁用');
    }

    // 返回用户信息（附加到 request.user）
    return {
      userId: user.id.toString(),
      userName: user.userName,
      roles: payload.roles, // 从 Token 中获取角色
      user, // 完整的用户对象
    };
  }
}
```

### 3. 权限验证流程

```
1. 从 request.user 获取用户信息
   ↓
2. 查询用户角色列表
   ↓
3. 查询角色关联的菜单/按钮权限
   ↓
4. 验证当前请求的路径/按钮是否在权限列表中
   ↓
5. 有权限则放行，无权限则返回 403
```

## 安全考虑

### 1. Token 安全

- **密钥管理**：使用环境变量存储 JWT 密钥，不要硬编码
- **Token 过期**：Access Token 2-4 小时，Refresh Token 7-30 天
- **Token 撤销**：支持黑名单机制（可选，使用 Redis）
- **HTTPS**：生产环境必须使用 HTTPS 传输

### 2. 密码安全

- **加密存储**：使用 BCrypt 加密，不要明文存储
- **密码强度**：前端验证密码强度（至少 8 位，包含字母和数字）
- **密码重置**：支持密码重置功能（可选）

### 3. 权限安全

- **最小权限原则**：默认无权限，需要显式授权
- **权限缓存**：使用 Redis 缓存权限信息，提高性能
- **权限变更**：权限变更后清除缓存，强制重新登录或刷新 Token

### 4. 接口安全

- **参数验证**：使用 class-validator 验证请求参数
- **SQL 注入防护**：使用 Prisma 参数化查询
- **XSS 防护**：对用户输入进行转义
- **CSRF 防护**：使用 CSRF Token（可选）

### 5. 日志和监控

- **操作日志**：记录用户登录、权限变更等操作
- **异常监控**：监控异常登录、频繁失败等
- **审计日志**：记录敏感操作（删除、修改等）

## AuthModule 配置示例

```typescript
// auth.module.ts
import { Module } from '@nestjs/common';
import { JwtModule } from '@nestjs/jwt';
import { PassportModule } from '@nestjs/passport';
import { ConfigModule, ConfigService } from '@nestjs/config';
import { AuthService } from './auth.service';
import { AuthController } from './auth.controller';
import { LocalStrategy } from './strategies/local.strategy';
import { JwtStrategy } from './strategies/jwt.strategy';
import { PrismaModule } from '@/shared/prisma.module';

@Module({
  imports: [
    // Passport 模块
    PassportModule,

    // JWT 模块配置
    JwtModule.registerAsync({
      imports: [ConfigModule],
      inject: [ConfigService],
      useFactory: (configService: ConfigService) => ({
        secret: configService.get<string>('JWT_SECRET'),
        signOptions: {
          expiresIn: configService.get<string>(
            'JWT_ACCESS_TOKEN_EXPIRES_IN',
            '2h',
          ),
        },
      }),
    }),

    // Prisma 模块（用于数据库操作）
    PrismaModule,
  ],
  controllers: [AuthController],
  providers: [AuthService, LocalStrategy, JwtStrategy],
  exports: [AuthService],
})
export class AuthModule {}
```

## 总结

本方案采用以下技术栈：

1. **Passport 认证框架**：`@nestjs/passport` + `passport` + `passport-local`
2. **JWT 认证**：`@nestjs/jwt` + `passport-jwt`
3. **密码加密**：`bcrypt`
4. **数据库 ORM**：`Prisma`（与现有项目集成）
5. **权限控制**：自定义守卫 + 装饰器
6. **缓存**：Redis（可选，提高性能）

**核心特点：**

- ✅ 使用 Passport Local Strategy 进行用户名密码验证
- ✅ 使用 Passport JWT Strategy 进行 Token 验证
- ✅ 双 Token 机制（Access Token + Refresh Token）
- ✅ 与 Prisma 集成，使用 Prisma Client 查询数据库
- ✅ RBAC 权限模型（角色 + 菜单 + 按钮）
- ✅ 细粒度权限控制（按钮级别）
- ✅ 动态路由支持
- ✅ 高性能（权限缓存）
