### 2. 创建的文件

#### 2.1 常量定义

- `src/common/constants/redis-key.constants.ts` - Redis Key 常量定义
  - `USER_TOKEN_KEY` - 用户 Token Key
  - `USER_VERSION_KEY` - 密码版本号 Key
  - `USER_INFO_KEY` - 用户信息 Key
  - `USER_ONLINE_KEY` - 在线用户 Key
  - `CAPTCHA_IMG_KEY` - 验证码 Key
  - `getRedisKey()` - 生成完整 Redis Key 的工具函数

#### 2.2 接口定义

- `src/common/interfaces/jwt-payload.interface.ts` - JWT Payload 接口定义

#### 2.3 装饰器

- `src/common/decorators/public.decorator.ts` - `@Public()` 装饰器
- `src/common/decorators/roles.decorator.ts` - `@Roles(...roles)` 装饰器
- `src/common/decorators/current-user.decorator.ts` - `@CurrentUser()` 装饰器

#### 2.4 策略（Strategies）

- `src/modules/auth/strategies/local.strategy.ts` - Local Strategy（用户名+密码验证）
- `src/modules/auth/strategies/jwt.strategy.ts` - JWT Strategy（Token 验证）

#### 2.5 守卫（Guards）

- `src/modules/auth/guards/local-auth.guard.ts` - Local Auth Guard
- `src/modules/auth/guards/jwt-auth.guard.ts` - JWT Auth Guard（支持 @Public() 装饰器）
- `src/common/guards/roles.guard.ts` - Roles Guard（角色验证）

#### 2.6 DTO

- `src/modules/auth/dto/login.dto.ts` - 登录 DTO
- `src/modules/auth/dto/refresh.dto.ts` - 刷新 Token DTO
- `src/modules/auth/dto/login-response.dto.ts` - 登录响应 DTO

#### 2.7 服务

- `src/modules/auth/auth.service.ts` - 认证服务
  - `validateUser()` - 验证用户（用户名+密码）
  - `login()` - 登录（生成 Token）
  - `refresh()` - 刷新 Token
  - `validateToken()` - 验证 Token（JWT Strategy 调用）
  - `logout()` - 登出

#### 2.8 控制器

- `src/modules/auth/auth.controller.ts` - 认证控制器
  - `POST /api/v1/auth/login` - 登录
  - `POST /api/v1/auth/refresh` - 刷新 Token
  - `GET /api/v1/auth/profile` - 获取当前用户信息
  - `POST /api/v1/auth/logout` - 登出

### 3. 配置更新

#### 3.1 AuthModule

- 配置了 PassportModule
- 配置了 JwtModule（使用环境变量）
- 注册了 LocalStrategy 和 JwtStrategy

#### 3.2 SharedModule

- 配置了全局 JWT 认证守卫（`JwtAuthGuard`）
- 配置了全局角色守卫（`RolesGuard`）

#### 3.3 应用配置

- `src/config/app.config.ts` - 添加了 JWT 相关配置
  - `jwtSecret` - JWT 密钥
  - `jwtAccessTokenExpiresIn` - Access Token 过期时间（默认 2h）
  - `jwtRefreshTokenExpiresIn` - Refresh Token 过期时间（默认 7d）

### 4. Redis 集成

所有 Token 和用户信息都存储在 Redis 中：

- **Token 存储**：`user:token:${userId}` - 存储 Access Token
- **密码版本号**：`user:version:${userId}` - 存储密码版本号（用于使旧 Token 失效）
- **用户信息**：`user:info:${userId}` - 存储用户完整信息（JSON 字符串）

所有 Key 都使用 `getRedisKey()` 函数生成，确保统一管理。

## 📝 环境变量配置

需要在 `.env` 文件中添加以下配置：

```env
# JWT 配置
JWT_SECRET=your-secret-key-here-min-32-chars-change-in-production
JWT_ACCESS_TOKEN_EXPIRES_IN=2h
JWT_REFRESH_TOKEN_EXPIRES_IN=7d
```

## 🚀 使用示例

### 1. 登录

```http
POST /api/v1/auth/login
Content-Type: application/json

{
  "userName": "admin",
  "password": "123456"
}
```

**响应：**

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "refreshToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
  }
}
```

### 2. 获取用户信息

```http
GET /api/v1/auth/profile
Authorization: Bearer {token}
```

### 3. 刷新 Token

```http
POST /api/v1/auth/refresh
Content-Type: application/json

{
  "refreshToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
}
```

### 4. 使用角色装饰器

```typescript
import { Controller, Get, UseGuards } from '@nestjs/common';
import { JwtAuthGuard } from '@/modules/auth/guards/jwt-auth.guard';
import { RolesGuard } from '@/common/guards/roles.guard';
import { Roles } from '@/common/decorators/roles.decorator';

@Controller('user')
@UseGuards(JwtAuthGuard, RolesGuard)
export class UserController {
  @Get()
  @Roles('admin') // 仅 admin 角色可访问
  findAll() {
    return [];
  }
}
```

### 5. 使用公开装饰器

```typescript
import { Controller, Get } from '@nestjs/common';
import { Public } from '@/common/decorators/public.decorator';

@Controller('test')
export class TestController {
  @Public() // 公开接口，无需认证
  @Get()
  findAll() {
    return [];
  }
}
```

### 6. 获取当前用户

```typescript
import { Controller, Get, UseGuards } from '@nestjs/common';
import { JwtAuthGuard } from '@/modules/auth/guards/jwt-auth.guard';
import { CurrentUser } from '@/common/decorators/current-user.decorator';

@Controller('user')
@UseGuards(JwtAuthGuard)
export class UserController {
  @Get('info')
  getInfo(@CurrentUser() user: any) {
    // user 包含 userId, userName, roles, user 等信息
    return user;
  }
}
```

## 🔒 安全特性

1. **密码加密**：使用 BCrypt 加密密码
2. **Token 管理**：Token 存储在 Redis 中，支持主动注销
3. **密码版本号**：当用户密码或权限被修改时，旧 Token 自动失效
4. **Token 一致性验证**：确保客户端 Token 与服务器存储的一致
5. **全局认证**：默认所有接口需要认证，除非使用 `@Public()` 装饰器

## ⚠️ 注意事项

1. **JWT_SECRET**：生产环境必须修改为强密钥（至少 32 个字符）
2. **Prisma Client**：如果修改了 Prisma Schema，需要运行 `pnpm prisma generate` 重新生成客户端
3. **Redis 连接**：确保 Redis 服务正常运行
4. **数据库迁移**：确保数据库表已创建（运行 `pnpm prisma migrate dev`）
